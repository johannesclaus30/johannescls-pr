04 / Cross-platform bookstoreMany sellers. A shared foundation.

A new chapter.
On every screen.

Booklat is a cross-platform, multi-vendor bookstore built with .NET MAUI Blazor Hybrid and Blazor Web. Customers discover books and shop across independent sellers, while vendors manage their own digital storefronts and orders.

BEHIND THE BUILDDifferent platforms. Shared thinking.+

A shared Razor Class Library (RCL) keeps reusable UI components, services, and core business logic together. Mobile, desktop, and web interfaces build on this centralized foundation, reducing code duplication and keeping shopping and vendor management consistent across platforms.

A place to shop. A place to sell.

Native shell. Familiar experience.

Native shell containers host Blazor interfaces, while reusable components and scoped CSS carry a responsive design from desktop to mobile.
