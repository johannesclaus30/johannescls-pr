# Tool logos

Logo candidates collected for the IT and Creative toolkit cards. Applied to the IT and Creative toolkit cards.

- Developer and design logos: Devicon (https://github.com/devicons/devicon). Devicon distributes its collection under MIT; brand marks remain their respective owners’ trademarks.
- Affinity and Canva: user-provided PNG replacements.
- CapCut: PNG from CapCut’s own asset host.
- React logo represents React Native. HTML and CSS have separate logo files for the combined card.

Exact download URLs are recorded in sources.json.
